# Flower follow-up orchestration

This directory binds the existing Flower stitch, metric, topology and finite
realization oracles into one Ike target. Flexible Pipes builds the pinned Ike
source and this receipt checker with the qualified ICK C17 compiler. Ike runs
each recipe through an absolute Grease executable; the recipe enters Kitchen's
absolute-path adapter before checked Ithon executes an AI-CI oracle.

The receipt checker requires the selected `accept` target, caller-supplied
SHA-256 identity of the literal `Ikefile`, external Grease runner identity,
exact rule and recipe order, zero recipe statuses and final PASS. Its
`self-test` mode proves that an unchanged checker rejects a forged target and a
forged final result.

inherited process values explicitly as `$[ENV.NAME]`; the receipt checker binds
that exact source. Flower Actions run 39083733337 preserves the failed recipe
and FAIL receipt.
