# Independent Unicode scalar ordering

The observer owns literal expectations for all five relations, empty strings,
proper prefixes, signed-bound decimal spellings, embedded NUL, combining text
without normalization and supplementary/BMP order. It calls only public checked
exports in the candidate DEX. A separately compiled candidate selecting Java's
UTF-16 comparator must fail the supplementary/BMP expectation with status 73.
Independent one-argument pure and managed IO entry checks retain their distinct
contracts. The observer is the only smali-assembled code; candidate semantics
remain compiled Idriç.

API, ABI, emulator identity, transferred DEX bytes, actual outputs/statuses and
the ai-ci source head are recorded. A passing decoder or host build does not
establish ART execution, a native reader or physical TAB_P10 acceptance.
