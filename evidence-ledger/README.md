# Source-bound evidence ledger checks

The [checked Ithon verifier](../examples/autogenerated/evidence-ledger/check.pi) independently checks a consumer's TSV contract against exact Git objects. The bounded implementation and Idriç/Ithon evidence are described in its [attempt record](../examples/autogenerated/evidence-ledger/attempt.md).

The contract is a six-column TSV: `operation`, `diagnostic`, `path`, `argument_1`, `argument_2`, `argument_3`. `rows` requires the exact number of data rows; `column_count` requires a particular value count at a zero-based column; `column_enum` permits a pipe-separated set; `git_manifest` requires a complete per-snapshot Git manifest, with snapshots supplied by argument 1. Unused arguments are literal `unused`.

Consumers retain the source/assignment judgments and positive/negative cases. The generic verifier recomputes the full manifest, source hashes and tabular assertions without importing the candidate generator. This does not authenticate a remote observer, establish university-wide coverage, prove interpretation, or authorize publication/merge.
