# Indeed proof-classification acceptance

This oracle uses the existing `equal` kernel assertion. It is independent of
the client implementation and resides in ai-ci, not in the candidate's
installation. Kitchen's Indeed task captures the actual installed executable's
audit output, projects identifier/category/supporting clause, and checks this
table. Replacing category 1 with category 5 must fail
`INDEED-PROOF-CLASSIFICATION`. Empty output and success-only printers also fail.

The descriptions are synthetic, from SUN INDEED-CLI-01's five categories and
negative requirements. A successful oracle verifies fixture classification,
not Indeed permission, real postings or nationwide counts. Transport and
installation have separate executed receipts. This does not certify arbitrary
natural-language classification; unrecognized requirements must remain unknown.
