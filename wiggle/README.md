# Independent mathematical movie acceptance

Owner assignment: https://github.com/isomorphisms/flexible-pipes/issues/250

`verify.pi` is checked Ithon. It imports no Flexible Pipes producer code. It
uses independently transcribed ATLAS M24 cycles, an independent rational-clock
evaluation, a direct DFT oracle, selected complex-polynomial/HCL pixels,
fresh selected jsurf viewpoints, Wegert zero/pole pixels, source-audio
reconstruction and AAC correlation. The existing ICK-built `aici-video` checks
finished media. An independent call to the pinned canonical Kitchen builder
must produce the same decoded per-frame pixel checksums as the candidate.

The three arguments are an absolute context TSV, the original input directory,
and the candidate output directory. The context supplies the pinned producer
checkouts, Ithon launcher, Java/classpath and Kitchen paths. The compiled
`aici-video` must be directly under the output directory. A fourth argument
selects one producer for adversarial tests only. Normal FP acceptance runs all
four. `source-pins.tsv` independently fixes expected producer origins and heads.

All old acceptance files are removed before verification. New verdicts are
written only after every selected producer passes and bind the verifier,
production and movie digests. An individual diagnostic must not be upgraded
to acceptance of an unselected producer. FP's final seal requires all four.

`test-mutants.pi` uses hardlinked evidence copies, atomically replacing mutated
files so original evidence remains intact. It checks the intended diagnostic
and absence of a success receipt for 17 bad evidence cases. Invalid timeline,
encoder failure, actual no-space and interrupted-output tests live with the FP
driver. These are offline host checks; they never certify live microphone,
Android GPU, install, touch interaction or physical A1/C67 capture.

The current route additionally requires an authored `motion-plan.tsv` and
`controls_visible=false`. Independent frame checks enforce contiguous complete
plan coverage, intent, held pixels and visible movement; Mathieu's scene viewport
also rejects UI pixels. Six additional known-bad cases repair upstream digests
and, for UI pixels, re-encode the altered frames through Kitchen before testing
the intended presentation boundary (23 evidence mutants total). Missing inputs
cannot bypass verification by dropping entries from the digest table.

The verifier is maintained source, not protected-review authority. Publishing
this candidate and its local receipts does not establish protected-controller
admission or authorize a merge.
