# Independent ChordReader managed execution

This observer calls the real `application_request : Text → Text` export from
the DEX asset extracted from the signed ChordReader APK. It never supplies a
replacement parser, spelling engine or reader implementation. The separate
ai-ci Smali oracle has nineteen literal expectations covering written intervals,
intentional chromatic spellings, recursive alterations, supplementary Unicode,
slash basses, major/minor declarations, Unicode chart offsets, fractional
scrolling, custom fingerings and malformed-input refusal.

The same unchanged oracle must reject the producer's compiled
`Music.transpose_note` source mutation with exit93 and the exact written minor
second diagnostic. A nonzero process alone is insufficient. Both API29 and
API34 run the positive and negative controls against byte-verified device files.
Independent baksmali decoding also runs on the actual APK asset.

The producer workflow separately owns installation, ordinary UI interaction,
real version1001→1002 data-preserving replacement, process-death recovery,
documents, setlists, diagrams and signed ARM packages. This bounded observer
does not claim to reproduce those interactions or physical TAB_P10 acceptance.

The oracle deliberately uses Smali to call the checked DEX ABI without sharing
the source compiler or the implementation under test. Its typed boundary is a
pair of Java String values compared by equality; rejection cases require the
explicit checked-error prefix. The Grease coordinator only stages immutable
bytes, executes ART and checks exit/diagnostic pairs. No fallback is permitted.
The application remains checked Idriç with C platform boundaries and Lua
presentation. This test code is not application code.

The workflow pins producer revision, run and artifact identity. Source receipt
and APK signer checks must precede observations; a producer revision change
requires a new artifact pin and another observation. No release or merge is
authorized here.
