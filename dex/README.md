# Checked Idriç calls acceptance

`CheckedCallsRunner.smali` observes a separately compiled candidate class. It
contains arithmetic/parity expectations, invokes public checked exports with
runtime arguments, checks cross-module behavior, recursive/mutual calls, six
reordered parameters and non-ASCII Text. It defines no candidate methods.

The canonical compiler fixture is
`isomorphisms/android-NDK/examples/autogenerated/checked-calls`. The candidate
must independently decode to actual generated-method invocations before ART
acceptance. Smali builds only this observer. Preserve candidate and runner
hashes, emulator identity, exact stdout and status. Mutate the checked helper's
addition and compile it again: this same observer must fail. Physical Android
acceptance remains separate.
