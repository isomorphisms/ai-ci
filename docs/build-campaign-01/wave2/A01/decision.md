These are separate release boundaries, not three reminders to obey instructions. Source work is ready; actual runtime qualification is conditional on exact eligible owner material.

The inspected main is [isomorphisms/ai-ci 949a60dad5e014cafce2c49619df9bbdbcfaafc0](https://github.com/isomorphisms/ai-ci/tree/949a60dad5e014cafce2c49619df9bbdbcfaafc0). `evals/cases.tsv` and `docs/evaluation-protocol.md` already encode constraint, correction and context-position tests but explicitly lack an executing semantic runner.
