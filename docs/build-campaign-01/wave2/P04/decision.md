Research2026-10-14; parent https://github.com/isomorphisms/ai-ci/issues/239; canonical https://github.com/isomorphisms/ai-ci/issues/225.

Three SUN handoffs complete the missing contract→extraction/admission→real consumer path. A separate fourth mandatory-gate job would edit the same verifier and split one inseparable enforcement boundary. CF02 owns the broader profile/matrix plan, CF07 signing/install admission, A03 generic policy authority and FP03 registered execution.

Contract decision: the application declares default application label, launcher component/alias identity, effective launcher label, icon reference and only explicitly required localization entries. Inheritance is an explicit valid relationship; empty output is not automatically success. Keep resource identity separate from decoded appearance: an icon reference check does not claim visual equality. Missing decisions block the affected presentation assertion; do not infer expected values from candidate badging or automatically activate every discovered locale.

The tuple binds exact application commit/contract digest, independently approved requirement provenance, Cat Food plan/profile digest, policy, extractor identity and final APK hash. Expected records and actual extraction are separately preserved. Duplicate/ambiguous fields and incomplete extraction reject. Candidate output can never choose its own assertion list or relax required policy. Same declared plan yields deterministic presentation obligations; resource ordering alone is harmless.

Edit order: CF02 freezes generic plan extension interface → P04-S01 presentation extension → P04-S02 extraction/assertion artifact → CF07 signing/install consumer over those exact bytes → P04-S03 real producer integration. P04-S02 must coordinate A03's authority interface and serialize android-companion changes with CF07; no whole-job cycle. Source implementation can begin before eligible extraction tools or isolated deployment exist. No physical display, replacement install or release was established here.
