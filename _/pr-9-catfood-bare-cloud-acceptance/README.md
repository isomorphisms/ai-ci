# PR #9 archive — Cat Food bare-cloud acceptance

This directory preserves the code, intent, and historical context of ai-ci PR #9, **“Exercise Cat Food from a bare cloud container.”**

It is reference material, not an active acceptance gate. Cat Food changed substantially after this work was written, so the old branch should not be merged merely because its central idea remains useful.

- `PURPOSE.md` records the intended independent-acceptance contract.
- `CONTEXT.md` records its relationship to Cat Food PR #16 and the architecture at the time.
- `STATUS-2026-09-23.md` records what should be reconsidered against current Cat Food and current ai-ci.
- `ORIGINAL-PR.md` preserves the PR description and metadata.
- `COMMITS.md` records the historical commits.
- `code/` contains every file changed by the PR, copied from exact head `438f08555a215c29479d81048cd8e31d930c674a` with its original path.

This archive is deliberately under the top-level `_/` directory so it remains available without presenting stale implementation as current repository structure.
