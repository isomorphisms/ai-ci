# Retained-source evidence

IB owns source representations, interpretation and per-source privacy. Drive
transport owns provider operations. AICI validates acceptance boundaries and
never supplies source bytes or fabricates an observation.

`retained-source-evidence.grease` is a narrow verifier for the deterministic
storage contract pipeline's TSV. It requires exact source/artifact identities,
passing intake/projection/stream/generation stages and independent NOT_RUN live,
physical and private-inspection gates. It verifies shape/evidence category, not
an untrusted author's truthfulness. Flexible Pipes records actual exit statuses
and output hashes; the test must execute the implementation's public entrypoint.

Real evidence remains separate: provider account/grant, original object version,
selected member coordinates and hashes, fixed mailbox source generation,
destination ID/size/checksum, Android package/signer/runtime and physical device.
Source absence is not a passing ingestion. A working Takeout range extractor is
not a ChatGPT decoder. An ordinary URL fixture is not a private Takeout shard.
Raw archival is not SPEC-LIST parsing/refiling. Missing provider digest/readback
must prevent exact-byte VERIFIED status. Stable Google client registration and
physical C67 consent are human gates; a hosted build cannot assert them.
