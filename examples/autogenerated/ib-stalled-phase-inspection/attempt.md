# Incomplete emulator phase inspection

The initial ecea API34 fragment and search attempts stopped producing output after successful native reader assertions. This read-only Grease inspector verifies their exact retained artifact byte counts and SHA256, then prints only ZIP entry names and lengths for the immediately following diagnostic phases. Empty or absent files locate unfinished observer work without asserting an Android cause.

Identity sketch: FrozenIncompleteArchive = fixed artifactId × byteCount × sha256; PhaseInventory = ZIP entry name × length. No source bytes, credentials, authorization material, bodies or screenshots are printed. The inspector cannot edit a candidate, run an emulator, rerun a workflow or cancel a job. It grants no positive product acceptance. App F43 and observer ecea remain unchanged; the two targeted retries already requested are independent of this inspection.
