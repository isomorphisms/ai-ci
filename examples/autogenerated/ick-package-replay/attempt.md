# ICK archive acquisition and independent compiler replay

## Type sketch and ownership

`acquire_archive : ArchivePath → ExpectedSha256 → FreshDirectory → action(MaterialRecord)` checks the externally supplied digest before creating the destination. Archive nodes have a relative canonical path, regular/directory/hardlink kind, mode and bounded size. Hardlinks must refer to an earlier regular archive member and become independent regular files. Symlinks, special nodes, duplicate paths and escaping names are refused before extraction.

`replay_compiler : PackageDirectory → ConsumerSource → ExpectedSourceSha256 → FreshDirectory → action(Observation)` consumes unchanged delivered bytes, a header-free real Fourier Voice leaf and the existing ICK glyph fixture. Its observations cover host execution and ARM assembly generation only. They do not authenticate an issuer, qualify Android linking/runtime, install on a managed host or establish mathematical equivalence.

Acquisition emits the existing SHA-256/mode/path `material.tsv` format. The established `package-closure/verify.grease` remains the independent material verifier; this adapter neither replaces that verifier nor claims its unavailable runtime passed. Source and archive provenance are external inputs, not producer assertions.
