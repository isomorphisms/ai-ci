# Independent evidence-ledger acceptance

INV-01 needs counts recalculated without importing its inventory generator. A manifest row cannot establish original bytes by itself.

## Type sketch

`read_rows : source_root → relative_path → action(List(List(Text)))` receives a rectangular UTF-8 TSV. `git_bytes : source_root → argument_list → action(bytes)` reads exact immutable Git objects. `manifest_matches : source_root → manifest_path → snapshots_path → action(Bool)` requires every declared snapshot tree entry exactly once, with matching mode, blob, length and SHA-256. `verify : source_root → contract_path → action(unit)` checks row counts, column enums/counts and the complete Git manifest.

Foreign filesystem, subprocess and SHA-256 results have explicit typed boundaries. No implicit Any, no synthetic course promotion from source manifests, no network fetching, and no modified source generator is used. Contracts are trusted policy inputs; this verifier is not a hostile-path sandbox, an authenticated issuer, or a syllabus interpretation model.

## Idriç-first prerequisite and implementation

The same INV-01 task's Idriç attempt is retained in bl4ckb4ll/syllabus `examples/autogenerated/inventory-reconciliation/count-source-records.idric`. Canonical compiler `2734ac5a86610eddfab73b1644d72b4ac85a65ee` exited 2 at its actual one-step emitter because the compiler was not bootstrapped. No Idriç typecheck/runtime result is claimed.

The broad consumer Ithon generator also exposes unsupported comprehensions. This independent verifier uses a smaller loop-only program that the existing checked host frontend **does** accept. It does not import or lower the rejected generator, and does not depend on its regular expressions or course-construction functions. Ithon `d6e83969f82512e920fb17b44326cb54f31d015c` checks these exact `.pi` bytes before host execution. The runtime substrate is inherited CPython, not a native Ithon build; no language/runtime substitute is hidden.

Consumer-owned positive contract and one targeted mutation per required rule live in bl4ckb4ll/syllabus `coverage/inventory.contract.tsv` and `coverage/aici-cases.tsv`. This is local bounded source acceptance. AICI current-head hosted CI, registered FP dispatch, trusted-policy admission and merge approval remain separate.
