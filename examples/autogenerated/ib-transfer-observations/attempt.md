# Retained transfer observations

The response owner already reports identity or chunked transfer decoding.
The existing independent receipt grammar now accepts exactly one optional
transfer_decoding observation with one of those literal values. All mandatory
fields and byte/digest/source checks remain required. Legacy receipts without
the field remain readable; absence never manufactures an observation.

The Grease harness calls the maintained independent source oracle on real
canonical publication fixtures, checking both observed values and the legacy
case. Host copies with an unsupported token or duplicate field must fail before
any positive marker. The producer also has a compiled observation-erasure
control. These are host receipt/byte checks, not an Android transaction.

Type sketch: a receipt has mandatory source identity, committed range and
response evidence, plus an optional closed TransferDecoding observation.
Unknown, duplicate and empty observations refuse. The existing AWK receipt
grammar owns host validation; no new general helper or alternate parser is
introduced. Grease owns orchestration. Current execution remains pending until
the exact IB integration runs these files using its pinned Grease runtime.
