# Independent presentation checks

`prepare.grease` compiles the actual IB retained-source adapter against an
independent expected history. Host execution covers source order, generations,
revision refusal, cursor preservation, corrupt/incomplete input, range bounds
and incompatible history versions. A separately compiled guard-bypass producer
mutation must fail the stale-revision assertion. Both producers emit real DEX.

`observe-art.grease` runs external reflection and semantic observers against
those source-generated bytes on an existing API 29/34/35 emulator. It rejects
both the revision-bypass producer and the incompatible callback-signature DEX.
This proves those boundaries; it does not prove a visible UI, callback dispatch,
frame timing, keyboard behavior, an imported archive, or physical acceptance.

The consumers keep their existing independent reader acceptance pinned
separately. These checks do not replace or weaken it.
