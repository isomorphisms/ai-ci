# Independent native C1 archive UI observer

The producer's C1 adapter and UI are tested through actual Android framework
Views in the installed app. The foreign Smali source is a test oracle, never
the application DEX producer. App-owned callbacks still come from Idriç.

Input types: immutable production APK, pinned assembler, existing public test
signer, asserted API/x86_64 emulator and a captured synthetic C1 archive under
the dedicated fixture package. Output types: verified/refused UI observations,
actual compositor PNG, installed-byte identity, signer receipt and before/after
private-file hashes. Generic failure is not a negative-control pass.

The observer checks actual text/role/identity, branch-mode callback, selectable
TextView and actual framework copy result; it rejects WebView/EditText in the
read-only entry. Production native code must not contain the synthetic URL.
Both initial read and process reopening must preserve all durable archive
bytes. A real normalized file is then corrupted in the asserted disposable
emulator namespace with original owner/mode; the app must show refusal and
expose no message text. A shell transport failure or crash cannot pass it.

The producer supplies a synthetic archive by its actual capture engine, then
updates the same signed fixture namespace to the actual production native
payload. The test namespace differs from the deliverable ARM64 app package;
neither execution on ARM64 nor user-data import is inferred from it.

Smali API29 assembly and Grease syntax have passed locally. Runtime and
physical acceptance remain pending until source-bound receipts are present.
Long Unicode paging, arbitrary branches/assets, full accessibility and device
input need additional independent coverage. No claim of completion is made.

The current observer also submits a real same-ID View to the app's actual
native callback on the main thread. A real current Button must remain enabled:
an admitted command disables it synchronously before worker publication can
run. The actual producer is then separately compiled with only its object-
identity guard deleted and signed with the existing fixture identity. That
installed mutant must fail precisely `FAIL same-ID archive control admitted`.
The archive bytes/UID must survive, and the unchanged production APK is
restored and byte-compared before the corrupt-provenance case. A reflection,
loader, timeout or other application failure cannot count as this refusal.

Producer b2ef2af6 passed both valid-view observations but its deliberately bad
producer crashed the target process instead of returning the required assertion.
That entire runtime gate failed. Android14 Instrumentation.SyncRunnable calls
the main-thread Runnable without catching its exception. The repaired task
records the actual Throwable and relays it to the instrumentation thread,
which reports its original diagnostic; the required assertion is unchanged.
The unchanged b2 APKs are requalified independently before any producer repin.

The independent job reconstructs the actual captured C1 disk archive with a
separately compiled verifier, checks the signed source/ABI/manifest inputs,
and seeds only a fresh asserted emulator fixture namespace. The UI must show
the actual independently computed normalized-source and inventory digests,
not merely any64-character strings. No producer status flag authorizes a pass.
