# Continuation verifier syntax repair

At8073611d, all observed native navigation/TLS/recovery and actual codec UI
steps still pass, but the new decoder verifier fails parsing a separated
elif token. Both codec proof and continuation touch therefore remain failed
or NOT_RUN at that head; the earlier EDB source-bound decoder proofs remain
scoped to their unchanged APK and observer. The continuation branch now uses
the required same-line } elif form, without changing its assertions.

A Grease -n guard parses all five changed active coordinator/oracle programs
before the candidate download and Android execution. Its receipt explicitly
reports runtime semantics NOT_RUN; actual source-byte mutation and SDK/ART
checks remain required. This prevents syntax regressions in new profiles
from wasting a complete emulator observation before discovery.
