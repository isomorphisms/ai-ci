## Contract before implementation

Values are finite lists of signed arbitrary-precision integer coefficients,
including degree zero. Requested order N means coefficients through qᴺ and
therefore N+1 entries. We check a source module exporting finite multiplication,
normalized E₄/E₆ coefficients, Δ coefficients and level-one prime Hecke action.

Mathematical signatures:

- divisor_power_sum : Number → Number → Number
- delta_reference : Number → List ±Number
- finite_product_reference : List ±Number → List ±Number → Number → List ±Number
- verify_candidate : FiniteCoefficientModule → AcceptanceResult

The Δ reference uses a logarithmic-derivative recurrence, independently of the
candidate's finite product and its E₄³−E₆² identity:

q Δ′/Δ = 1 − 24 Σⱼ≥₁ σ₁(j) qʲ,
τ(1)=1 and (n−1)τ(n)=−24 Σⱼ₌₁ⁿ⁻¹ σ₁(j)τ(n−j) for n≥2.

Every recurrence division must be exact. This is formal finite coefficient
arithmetic; no infinite analytic identity, modularity proof or convergence
claim is accepted by this program. E₄/E₆ references enumerate divisors directly;
the candidate uses a divisor sieve. Hecke checks include arbitrary exact input,
constant terms, eigenform examples and rejection of insufficient input order.

Effects: read one explicit absolute candidate path, compute its SHA256 and verify
an expected hash when supplied (otherwise the controller must bind the hash),
import those exact bytes as a self-contained JavaScript module, run independent
checks and known-bad mutants, and emit plain TSV. No source modification,
network operation, compilation or publication occurs.
