# Independent retained-journal recovery

Purpose: distinguish a byte-valid metadata file from a valid browser history.

The reader-v6 ART profile invokes the actual checked Activity export with
literal source/generation/journal cases: selected source, selected generation,
cursor bounds, canonical framing, incomplete lines, empty history, generation
overflow and legacy empty journals. A compiled Activity source mutant must
fail at the exact independent assertion (137 plus its designated text).

The navigation reader-v4 profile preserves all prior installed transport,
link, history, source copy, update and readback checks. With Shizuku absent it
independently verifies the observed three-document Arena and both index heads,
then changes the selected cursor while retaining the current source identity,
recomputes the metadata checksum and writes that complete owned head while
the emulator app is stopped. It reads back the exact corrupted file before
launch. The actual app must visibly recover Reader One from the previous
head, preserve exact source copy, and support Forward/Back/Forward to Reader
Two. The independent final verifier rechecks the ordered identities, source
generations and literal fixture body digests. Arena source bytes must be
identical before and after this recovery. There is no network or original
source replacement.

SDK/ART observation code is an independent boundary, never candidate reader
implementation. The test corruption is confined to the emulator's
instrumented fixture application; no physical/user installation is changed.

Types: exact ASCII index bytes and their SHA-256 are observations; opaque
source identity and generation remain distinct from selected history
coordinates. Candidate Idriç decides journal meaning. The test does not
reimplement that parser as the implementation.

At authoring this profile is NOT_RUN and is selected explicitly; frozen
reader-v5 replay inputs do not acquire this new claim by file presence.
Physical TAB_P10 remains BLOCKED. No old failure or old pass is rewritten.
