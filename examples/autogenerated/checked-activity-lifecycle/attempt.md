# Independent framework resume and destroy observation

The candidate comes only from the maintained checked Idriç compiler. This SDK observer is a separate test APK. It never supplies or rewrites candidate methods. Its literal expectations are Created after onCreate, Resumed after onResume and Destroyed after onDestroy. Android launches the original Activity, starts a second instance through the first, finishes the second, and automatically returns to the original. The oracle changes the original title to Before return before leaving, so a stale title cannot stand in for a new resume callback.

Two independently compiled Idriç source mutants replace the resume or destroy title with Wrong. Only the corresponding exact SDK assertion qualifies each rejection; a crash, timeout or verifier failure cannot count. Reinstalling the original DEX must restore the positive behavior. The oracle independently decodes the actual candidate DEX and checks superclass dispatch before the checked static receiver for both callbacks. Packaging compares source DEX to packaged and installed bytes; update UID and the existing public test certificate are checked. The qualification namespaces contain no IB application data and no package is uninstalled.

Type sketch: observe : CompiledActivity × FrameworkEventSequence → LiteralSemanticObservation. The observer owns events and expectations; the compiler owns checked candidate methods.
