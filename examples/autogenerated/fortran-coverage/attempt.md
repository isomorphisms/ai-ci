# Independent archived-corpus checker

Inputs: a leaf Git repository with pinned source snapshots and candidate TSVs.
Output: a mechanical acceptance decision and targeted mutation observations.
The checker independently reads original Git blobs and GNU readelf results;
it does not import the producer, trust summary totals, or execute QR code.

Domains: artifact identity, file interval, instruction record, section, relocation,
annotation correspondence, and incomplete semantic claim. Whole-language and
library closure denominators remain unknown. Every claimed row needs raw evidence.

The paired Idriç choice-model attempt in the leaf used the real compiler at
2734ac5a86610eddfab73b1644d72b4ac85a65ee and exited 2 because the compiler was
not bootstrapped. Node is a bounded one-off filesystem/hash/binutils fallback,
not Idriç acceptance. Its independent method uses binutils section/symbol/relocation
reports and separately parsed original listing columns rather than producer code.

The first language capability needed to remove this fallback is the bootstrapped
direct-host compiler and checked byte/file/subprocess interfaces. A port must pass
the original corpus and reject the same targeted corruptions. No replacement
compiler, RefC, unverified semantics or success-only wrapper qualifies.
