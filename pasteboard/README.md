# Independent Fixed Pasteboard qualification

`prepare.grease` builds the checked Idriç oracle and independent NativeActivity
copy fixture. The fixture performs SDK clipboard effects only in response to
visible input; it cannot call the consumer model or history provider.
`observe-art.grease` executes the exact reducer DEX extracted from the candidate
APK and compares every result with explicit independently authored expectations.
It must reject the separately source-compiled wrong-order mutant at case 2.

`observe-installed.grease` is an emulator-only acceptance procedure. It verifies
the emulator and shell identity before changing display geometry, starting the
official pinned Shizuku server, or inspecting private synthetic fixture history.
The decisive A/B/C check reads durable history while the copy fixture remains
focused, then checks it again after Pasteboard resumes. Permission decisions use
the real Shizuku dialog and confirm that it names Pasteboard. No clipboard
polling or accessibility content extraction is used by the candidate.

The oracle checks checksums, strict UTF-8, framed snapshots, unique identities
and contents, visible capacity and exact expected text/order independently of
consumer code. Bad checksums, malformed framing, invalid UTF-8, duplicate records
and the compiled semantic mutant have distinct refusal controls. Fixture text
includes indentation, CR/LF, code fences, supplementary Unicode and more than
8192 bytes. Only synthetic fixture history may enter these evidence artifacts.

Record separate results for host tests, DEX/ART, installed loader, privileged
callback delivery, user workflow and physical deployment. Current scripts cover
the initial positive workflow, denial/unavailability, text policies and ordinary
process/replacement persistence. Manager revocation, observer crash/reconnection,
clipboard expiration, v1 migration, destructive-action UI, backup deletion and
reboot coverage are still acceptance obligations. A partial result table is not
a complete qualification receipt. Gboard itself and physical C67/TAB_P10 must be
reported separately from preserving an emulator's existing keyboard setting.
