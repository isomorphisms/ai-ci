# Independent bounded native-capture receipt check

`check.c` links no exporter implementation. Its expected semantic IDs are the
five declared synthetic conversations. It hashes independent raw fixture files,
then checks exact persisted bytes, inventory-bound completion markers, expected
journal records, private ownership/modes, incomplete-account reporting, and
unfiltered exact-head CI eligibility. The existing TypeScript envelope/graph
tests independently check the fixture meanings, including alternate branches
and unknown roles. A capture's own success report cannot issue this PASS.

Compile this maintained verifier through the declared source-pinned ICK stage.
An explicitly labelled host `cc` fixture run proves only host artifacts. Run
`check NATIVE_DIRECTORY FIXTURE_DIRECTORY EXPORTER_WORKFLOW`, then
`check --reject-skipped-trigger native-capture/fixtures/skipped-trigger.yml`.
No account, credential, network operation, device or controller is exercised.

The caller must bind exact exporter, verifier, fixture and workflow source
hashes. These checks do not certify a deployed FP controller or visible sink,
physical disk survival, Android, browserless authentication or account export.
